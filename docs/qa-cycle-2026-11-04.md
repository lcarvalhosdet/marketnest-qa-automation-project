# QA cycle before release, Nov 4, 2026

**Recommendation: no-go.** Updated Nov 5 after a regression pass (BUG-022 to BUG-025).

Main blockers:

- GDPR: consent bugs BUG-003 to BUG-006, incomplete Privacy Policy (BUG-007), incomplete data export (BUG-017)
- Money: option surcharge mismatch (BUG-012), tax before discount (BUG-019), seller fee ~11% (BUG-018)
- Search 500 on common characters (BUG-009)

Details: [bug-reports.md](bug-reports.md). Table: [README.md](../README.md#known-bugs).

## Scope and environment

- **App**: https://qa-marketplace-app-b9mpo.ondigitalocean.app (shared demo, other people add products during the run)
- **Browsers**: Chromium 1280x720 and iPhone 13 viewport. Did not run Firefox/WebKit this cycle.
- **How**: manual exploration + Playwright (network, cookies, storage, headers, layout). Bugs got automated tests after.
- **Accounts**: guest pass first (no account created). Signed-in pass used my test account (already had a shop + one order). Saved one fake address, flipped marketing off, cart exercised through checkout. No order placed. Account not deleted.

## Automated coverage

Most findings above have a failing or passing automated test. Regression coverage also includes
cart/coupons, checkout validation, stock, search, filters, pagination, shops, account edits,
mobile layout, a11y and load time. Full list: [test-catalog.md](test-catalog.md).

`tests/account/` needs a saved session (see README). Those tests restore account state and skip
the account's own shop products. Privacy-only run: `npm run test:gdpr`.

## Not tested

- Delete my account (irreversible). Use a throwaway account.
- Place order / card decline / cancel / refund / returns. Did not enter card details. Checkout shows demo cards.
- Reviews (verified buyers), create/edit listings, ship an order.
- Password flows: login errors, forgot password, password rules. Skipped for now.
